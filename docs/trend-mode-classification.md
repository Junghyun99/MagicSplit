## 설정 구조

- `large_cap_ks`: 글로벌 플래그를 상속한다. 현재 테스트 설정에서는 기본적으로 추세 전용이다.
- `cyclical_quality_ks`: `trend_only_enabled=false`인 박스권·경기순환 프리셋이다.
- `consumer_staples_ks`: `trend_only_enabled=false`가 기본이다.
- 삼양식품은 소비재 프리셋의 금액·매매 기준을 사용하면서 종목별 `true`로 재정의한다.

이 분류는 사업 성격을 반영한 초기 가설이다. 최종 채택 전에는 전체 OFF, 전체 ON, 현재 혼합 분류를 같은 기간과 비용 조건으로 비교해야 한다.
