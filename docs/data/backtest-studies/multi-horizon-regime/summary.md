# 장·단기 추세 3층 레이어 ON/OFF 스터디

두 군은 63봉 `channel` 레짐, 종목·기간·초기자본·나머지 설정을 동일하게 유지합니다.

최종 평가액은 백테스트 종료 시점 값이며 MDD는 일별 스냅샷 기준입니다.
